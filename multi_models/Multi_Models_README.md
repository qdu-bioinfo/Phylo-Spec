# Instructions

Run all SOTA models using Multi-comparison-models.py.

*i.* **Model 5 CNN** and **Model 2 RF** No additional input is required, only '-c', '--csv', type=str, required=True, help='Path to input CSV file'

*ii.* **Model 4 DeepPhylo** requires input of 3 'npy' files ' X.npy' , 'Y.npy' and 'embedding.npy'.

'X.npy' and 'Y.npy' can be obtained through **trans_npy.py** in the DeepPhylo folder. The input requirement is a 'csv' file, delete the first row of feature names, delete the first column 'SampleID', delete the last column 'Group' disease status, and only keep the numerical part of the feature table as the generation condition of 'X.npy'. Only keep the last column of disease status and encode it as binary 01 as the generation condition of 'Y.npy'.

'embedding.npy' can be obtained through **mysystem_rpca.py** under the deepphylo file in the DeepPhylo folder. The first input is a 'csv' file, the first column is 'SampleID', the last column is the 'Group' disease status column, and the remaining columns are feature columns. The second input is the '.nwk' file, which is a phylogenetic tree.

*iii.* **Model 3 PM-CNN** requires input '-c', '--csv', type=str, required=True, help='Path to input CSV file'.

Secondly, you also need to input the hierarchical clustering 'list.csv' file generated by PM-CNN. It can be generated from **PMCNN_list.py** in the PMCNN folder.

The inputs of PMCNN_list.py are '-t', '--tree', type=str, required=True, help='Path to Newick tree file' and '-c', '--csv', type=str, required=True, help='Path to input CSV file'

*iv.* **Model 1 MetaDR** requires inputs of '-t', '--tree', type=str, required=True, help='Path to Newick tree file' and '-c', '--csv', type=str, required=True, help='Path to input CSV file'

After all the above work is prepared, you can execute the command



```
python Multi-comparison-models.py \
  -c /path/to/xxx.csv \
  -t /path/to/xxx.nwk \
  -l /path/to/PMCNN_list_xxx.csv \
  -npy /path/to/X_xxx.npy /path/to/y_xxx.npy /path/to/embedding_xxx.npy
```



Note: For MetaDR and PM-CNN, the dimension of the first layer 'nn.Linear' input after 'nn.Flatten()' is not automatic and needs to be modified manually.
